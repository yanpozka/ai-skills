# socratic-learn

A tutor skill. You produce the attempt. The model asks one question, names the gap, and waits. It does not open with a lecture, summarise a text you have not read, or write work you will submit.

Use it with `/socratic-learn`, or by asking to be taught, quizzed, or walked through a paper.

Modes: Socratic questioning, an explanation ladder (child, then secondary-school, then specialist), Bloom's taxonomy, retrieval quiz, reading compare, draft feedback, and error hunt.
