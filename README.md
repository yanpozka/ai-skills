# ai-skills

A list of personal AI skills I have built for myself

## Skills

| Skill | What it does |
| --- | --- |
| [socratic-learn](socratic-learn/) | Tutors by questioning. You make the attempt; the model asks one question, names the gap, and waits. Drawn from Oxford's AI study guidance, Mollick and Mollick, and the CLEAR framework. |
| [hledger-books](hledger-books/) | Imports a bank or card CSV into [hledger](https://hledger.org), categorizes it, and reconciles to the balance on the institution's page. A second running total in the CSV is not a second account. |

Invoke a skill by name, for example `/socratic-learn`, or ask to be taught, quizzed, or tutored.
