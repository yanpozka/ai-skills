# hledger-books

Keeps plain-text books in hledger: import a bank or card CSV, categorize it with rules, and reconcile to the balance on the institution's page.

The CSV Balance column is not that balance until it is checked. A second running total in the same column is not a second account. The worked failures in the skill name no institution, account, amount, or date.

Use it with `/hledger-books`, or by asking to import, categorize, or reconcile an hledger journal.

Entity-specific accounts and tax decisions stay in the project's own notes. This skill is the procedure.
